# 01. Архитектура и развёртывание

[English](../../design/01-architecture.md) · **Русский**

## Компоненты

```text
 Claude Code / Desktop ─MCP (streamable HTTP, Bearer)──┐
 assistant agent ───────REST (Bearer)──────────────────┤
                                                       ▼
                               nginx (mem.example.com, TLS)
                                                       │
                                  127.0.0.1:3120  ┌────┴──────────────┐
                                                  │  mem-api           │
                                                  │  FastAPI + MCP     │
                                                  │  (один процесс)    │
                                                  │  embedder (ONNX)   │
                                                  └────┬──────────────┘
                                                       │
                                            ┌──────────┴─────────┐
                                            │ Postgres 16        │
                                            │ + pgvector         │
                                            │ (отдельный,        │
                                            │  mem_db)           │
                                            └────────────────────┘
                        mem-worker (тот же образ, режим job): лёгкий сон 03:30 ежедневно, глубокий — вс 04:00 (MEM_TZ)
```

| Компонент | Технология | Почему |
|---|---|---|
| API + MCP | Python 3.12, FastAPI, официальный Python MCP SDK (streamable HTTP), один процесс, общий сервисный слой | P7: один код для REST и MCP |
| Эмбеддинги | ONNX-модель через `fastembed` (без torch), в процессе API | P9 локально; без отдельного сервиса |
| Модель | **`intfloat/multilingual-e5-small` (384)** — выбрана бенчмарком 24.09.2026 из трёх кандидатов (`docs/research/embed-benchmark.md`) | Качество на русском проверено на канарейках |
| БД | Postgres 16 + pgvector (HNSW), FTS с конфигурациями `russian` и `english` | Один движок, знакомая эксплуатация |
| Миграции | SQL-файлы `migrations/NNNN_*.sql`, свой раннер с advisory-lock; при старте сервис сверяет применённые миграции, размерность и модель векторов и не стартует при расхождении (без ORM — Alembic не нужен) | P10 |
| Ночная задача | тот же образ, `python -m mem.jobs.nightly`, cron в контейнере-планировщике | Отдельный процесс, не мешает API |
| LLM (только глубокий сон) | Claude через Anthropic API: противоречия и слоты — Sonnet, сводки — Haiku; ответы по JSON-схеме | F-8 |

## Размещение

| Параметр | Значение |
|---|---|
| Запуск | `docker compose up -d`, compose-проект `mem` (явный `name:` в compose) |
| Порты | API `127.0.0.1:3120`; Postgres без публикации; наружу — через nginx с TLS |
| Бэкап | `pg_dump` по расписанию, шифрование, 14 дней; + ночной JSONL-экспорт каждого пространства |

### Ресурсы

| Контейнер | Лимит |
|---|---|
| mem-api (с моделью) | 1536 МБ (факт в покое ≈ 820 МБ) |
| mem-worker | 512 МБ (запускается на время задачи) |
| mem-postgres | 512 МБ |
| **Итого** | **≈ 2,5 ГБ** |

### Расписание (по умолчанию, часовой пояс MEM_TZ)

| Время | Задача |
|---|---|
| 03:30 | Лёгкий сон, ежедневно (05 §3) |
| 04:00, воскресенье | Глубокий сон (уборка), после лёгкого; отчёт — агенту для владельца |
| 05:30 | Бэкап |

## Безопасность

| ID | Требование | Тип |
|---|---|---|
| S-1 | Аутентификация: `Authorization: Bearer <token>`, токены в таблице `clients` (хранится хэш). Токен принадлежит участнику (08); его пространства и права — **потолок**, сам доступ даёт грант участника (для агента — его человека) | DET |
| S-2 | Токены клиентов: `cowork` (work: read/write/review), `claude-code` (work: read/write), `assistant` (assistant: read/write/review/forget — `review` и `forget` вызываются только после моего нажатия в боте), `admin` (всё, только из localhost) | DET |
| S-3 | `purge`, экспорт и админ-операции — только с правом `forget`/`admin`; массовое удаление требует фильтра и `dry_run=false` + `confirm=<число записей>` (урок: массовое удаление без подтверждения опасно) | DET |
| S-4 | nginx: наружу только `/mcp/` и `/v1/`, `/status` — по неугадываемому пути; сканеры → 444 (есть `default_server`) | DET |
| S-5 | Тексты записей не логируются; в `audit_log` при purge — только id, пространство, правило | DET |
| S-6 | Эмбеддинги и поиск — локально. Во внешний LLM уходит только глубокий сон: тексты записей и цитаты одного `subject` за раз, только в Anthropic API (тот же обработчик, что уже видит сообщения у агента), записи с `visibility = owner_only` — не уходят никогда | DET |

## Критерии приёмки

- `ss -tlnp`: только `127.0.0.1:3120` для mem.
- Запрос без токена → 401; токен `cowork` к пространству `assistant` → 403.
- Массовый `forget` без `confirm` → 400, ничего не удалено.
- `docker compose ls` показывает проект `mem`, тома `mem_*`.
